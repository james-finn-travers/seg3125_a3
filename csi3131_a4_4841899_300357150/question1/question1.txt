A page-replacement algorithm should minimize the number of page faults. 
We can achieve this minimization by distributing heavily used pages evenly over all of memory,
rather than having them compete for a small number of page frames. 

We can associate with each page frame a counter of the number of pages associated with that frame.
Then, to replace a page, we can search for the page frame with the smallest counter.

a. Define a page-replacement algorithm using this basic idea. 
Specifically address these problems: 

i. What the initial value of the counters is 

the initial value for each counter would be 0.

ii. When counters are increased 

the counters increase whenever the current page matches the page of the counter's corresponding frame.

iii. When counters are decreased 

The counters are decremented when the corresponding frame's page is replaced by the current page to resolve a fault.

iv. How the page to be replaced is selected 

The page with the smallest counter value will be replaced during a fault
